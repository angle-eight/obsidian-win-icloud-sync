# プロジェクト定義 (project.md)


## 1. プロダクト概要
ObsidianのiCloud同期がWindowsでは機能しないため、それを解消するためのアプリ。
Obsidian用にはLocalで任意のObsidianフォルダを設定し、iCloudのObsidianフォルダと定期的に同期する。
同期は前回同期時から変化が合った方で上書きするというシンプルな形。
localとicloudの両方に変化があった場合は差分を表示し、どちらを採用するか選ばせる。(暫定機能、今後より高度化)
localのObsidianフォルダの場所や同期間隔などはjsonファイルで設定させる。
常駐アプリを目指すが、まずはコンソール版を作成し動作を確認する。
